# Cognetix MERN Internship Projects

Nine independent MERN projects based on the Cognetix Technology Full Stack Developer Internship Handbook.

## Projects

1. `01-weather-app` - OpenWeather search and unit conversion
2. `02-expense-tracker` - Authenticated income and expense tracking
3. `03-product-landing-page` - Responsive product showcase
4. `04-blog-management` - Authenticated blog CRUD
5. `05-recipe-sharing` - Recipe CRUD, image metadata, and filtering
6. `06-notes-app` - Private authenticated notes
7. `07-ecommerce-store` - Products, cart, checkout, and orders
8. `08-job-portal` - Candidate, employer, and admin workflows
9. `09-food-ordering` - Menu, cart, checkout, and order tracking

Each folder is an independent MERN project with its own `backend`, `frontend`, package manifests, environment example, and documentation.
